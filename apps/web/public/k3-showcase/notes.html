03KDA 与 MLA：长记忆 + 定期全局复盘

KDA：固定大小的递归状态

Kimi Delta Attention 用状态矩阵 S 逐 token 更新。它先按通道遗忘旧状态，再用 delta rule 写入新键值，避免完整 KV 缓存随序列一直增长。

S_t = (I - beta k k^T) Diag(alpha) S_(t-1) + beta k v^T
output_t = S_t^T q_t

训练和 prefill 时按 chunk 并行、chunk 间递归。K3 把 log-decay 下界设为 g_min = -5，使 16-token tile 的数值范围留在 BF16 可承受范围，所有因果 tile 可走 Tensor Core 稠密矩阵乘。

Gated MLA：压缩后的全局注意力

Multi-head Latent Attention 把每个 token 的 K/V 压入低维 latent，只缓存 latent，需要时再上投影，因此比缓存完整多头 K/V 更省。

K3 的 MLA 使用 NoPE，不显式加入位置编码；KDA 的递归门控负责位置敏感与近因信息，MLA 负责不受限制的全局内容交互。全秩输出门让每个 token 决定读取哪些输出通道。

报告事实主干以 3:1 重复 KDA / Gated MLA，末尾额外保证一层 MLA；总计 69 层 KDA、24 层 MLA。训练中 MLA 的 attention output 保留 FP32，以校正 flash attention 的偏置舍入误差。
谨慎解读可把 KDA 想成随身压缩笔记，容量固定、持续更新；MLA 像定期翻阅整本资料。混合设计是在长上下文成本与全局精确读取之间折中，并非 KDA 完全替代标准注意力。

普通残差连接不断把所有旧信息累加到一个状态，像把每页笔记揉成一团继续传。Attention Residuals 为当前层学习一个 pseudo-query，对 embedding 与先前层输出做 softmax 加权，选择性取回所需深度的信息。

05Stable LatentMoE：稀疏到 896 个专家仍要稳

LatentMoE 把“公共能力”和“专门能力”拆开：2 个 shared experts 处理完整宽度 7,168；routed experts 在 3,584 的半宽 latent 中工作。这样每 token 选 16 个专家时，通信和权重流量不会按完整模型宽度膨胀。

RMSNorm：先稳住尺度

路由聚合 u 的大小会随专家和权重变化。K3 在上投影前插入 RMSNorm，再与 full-width 共享路径合并。报告称这不仅稳定训练，也持续改善验证损失与下游评测。

SiTU-GLU：给乘法加软上限

SwiGLU 的两条乘法分支都无界，低精度下容易产生 outlier。SiTU 对 gate 线性因子和 up 分支分别做 beta·tanh(x/beta)，K3 取 beta1=4、beta2=25，理论幅值上界为 100，同时原点附近近似 SwiGLU。

QB：不靠固定步长猜负载

Quantile Balancing 仍用专家 bias 改变 Top-k 派发，但不把 bias 混入专家加权与 router 梯度。它根据每个专家 router margin 的目标分位数直接求下一步 bias，使目标负载 q = m·k/n。全局批量过大时，用每专家几百个 bin 的直方图加一次 all-reduce 估分位数；推理时冻结最终 bias。

报告事实附录称 QB 的通信是每层每步一次 nB 个整数的 all-reduce，和 token 数 m 无关；在其配置下，不到收集原始 margins 方案成本的 1%。

06原生视觉与 Per-Head Muon

MoonViT-V2 从零一起训

  • 文本、图像、视频从预训练一开始共同做 next-token prediction，不做后接视觉塔的对齐阶段。
  • 27 层、约 0.4B 参数、patch size 14、12 个头；RMSNorm，线性与注意力投影去 bias。
  • 图像与视频共享参数；空间 / 时间注意力分解，时间池化压缩视频 token。
  • 2×2 pixel shuffle 让视觉 token 数降 4 倍，支持最高 3584×3584 输入。

Per-Head Muon 分头正交化

Muon 用 Newton-Schulz 对矩阵动量正交化。K3 不把完整 Q/K/V 当成一大块，而是沿 attention head 切分后逐头处理，避免大梯度头主导共享更新方向，使不同头的更新尺度更平衡。

报告结论：大规模下训练更稳定，且高瘦的逐头矩阵让优化器开销略低。

事实边界报告发现从零训练 MoonViT-V2 的梯度更稳，视觉评测与 SigLIP 初始化基线相当。这支持“该规模下不必依赖对比预训练作为初始化”，不代表对所有模型规模与数据预算都成立。

SFT

以前代 Kimi 专项模型合成轨迹，经多阶段核验和人在回路标注；XTML 统一序列化复杂工具轨迹。目标是自适应推理、精确工具调用和长程执行的高质量起点。

RL

三领域为一般任务、一般智能体、编码智能体；每个领域训练 low / high / max 三种 reasoning effort。按题估计初始 token 预算 b0，超出 tau·b0 的轨迹奖励置 -1，再逐阶段降低 tau 控制过度思考。

MOPD

学生按领域 d 与 effort e 在自己的 on-policy token 上，获得对应教师与学生 log-prob 比值形成的逐 token 稠密奖励，并截断极端信号。论文称 top-k 蒸馏在此设置中没有明显优势。

部分 rollout

N×K 轨迹只要 lambda 比例完成就开始优化，未完成轨迹排队到下轮继续。每 token 正则让算法容忍跨迭代产生的陈旧 off-policy 数据，减少长尾等待。

QAT 与 EAGLE-3

  • QAT：从 SFT 起覆盖整个后训练，包括 RL。占参数内存大头的 MoE routed expert 权重用 MXFP4，输入激活用 MXFP8；attention、latent 投影、shared expert、router 保持高精度。rollout 与训练同量化方案，避免 train-inference mismatch。
  • EAGLE-3：把预训练 MTP 层微调为单层 draft model，冻结目标模型；融合第 1、第 4、最终 AttnRes block 的低 / 中 / 高层特征，训练展开 7 步，并直接用接受率的负对数 LK loss 优化无损投机采样。

09任务环境：奖励必须落到可验证结果

统一白盒 harness

工具、系统提示、上下文管理、skills、memory、subagents 均可组合，动态生成 Kimi Code、Claude Code、Codex、OpenClaw、Hermes 等配置，减少对单一脚手架过拟合。

知识图谱合成

智能体递归扩展有向无环概念图，按不同粒度采样节点，检索公开材料后生成知识与编码任务，控制覆盖和细粒度。

可验证专业任务

复杂搜索、投行、数据分析、法律、视觉 STEM；沙箱内用 Python 裁剪、缩放、变换与计算，执行输出作为下一步观察。

GPU kernel

CUDA、Triton、CuTe DSL 等，覆盖 BF16 / FP8 / FP4；超过误差阈值奖励归零，速度对标专家与 roofline，并检测缓存、精度偷降等 reward hacking。

个人助理 living world

模拟 Gmail、Notion、Slack、Canvas，多应用、多天、相互依赖事件；单次 rollout 可达数千工具调用与数百万上下文 token。

AET 与 WebDev

Autonomous Execution Task 只给目标、约束、工具和独立 verifier；公共 / 隐藏 verifier 隔离。WebDev 再加构建、功能、结构、像素与模型评审。

谨慎解读后训练重点不只是“会答题”，而是把计划、操作、反馈、恢复、终止放进可持续的环境循环。可验证终态比模型自称“完成了”更可靠，但 verifier 本身仍可能有覆盖盲区。

10训练、RL 与服务基础设施

训练：让 3T 稀疏多模态跑得动

KDA 协同设计

FlashKDA 让 token 并行阶段与跨 chunk 状态传播重叠；KDA Context Parallelism 每 rank 计算局部转移 M 与从零生成状态 S~，一次固定大小 all-gather 后按结合律前缀扫描，获得线性计算扩展。

MoonEP 完美负载

动态冗余专家保证每 rank 精确接收 S×K token；每 rank 预留最多 E/R 个冗余专家即可保证可行。静态 shape 去掉逐层 host 同步，zero-copy 派发缓冲固定为 S×K。

内存管理

统一 activation manager 按 tensor 组合重算、FP8 量化、CPU / 远程卸载；Pipeline ZeRO-2 分片梯度并放 CPU；P2P Muon 只取本 rank 所属参数分片，不做全参数 all-gather。

隐藏视觉开销

大图按 patch 跨设备动态 CP；多个图像分入子 CP 组做均衡。ViT forward / backward 拆开并塞入 interleaved 1F1B pipeline bubbles，报告称大部分视觉编码计算可被隐藏。

1M Agentic RL：状态不能丢

  • co-located 训练 / rollout 使每个实验控制在数百 GPU；外部 CPU DRAM KV pool 只在 GPU 驱逐可复用前缀时 write-back，KDA state 与 MLA KV 同生命周期。
  • 根据活跃数、排队数、KV 利用率自动节流；训练后把权重与优化器状态卸到 NVMe，为 rollout 前缀池腾 DRAM。
  • AgentENV 用 Firecracker microVM；增量 checkpoint / resume 最低 133ms / 49ms，pause 时可释放等待推理所占资源，真实负载内存超配最高 6.5x。
  • 训练与评测累计创建 51,219,741 个 sandbox，来自 1,505,678 个镜像。

服务：两种缓存一起管

KDA state 固定大小，MLA KV 随序列增长。服务端把两者装进统一 paged pool，但将 512-token 细 hash block 与 1,024 至 6,144-token 物理块解耦，只在稀疏 hash 边界保存 KDA checkpoint。命中必须同时拥有 MLA prefix 与所有 KDA group checkpoint。

典型流量报告给出的 1M 编码请求常有 400K prefix、只新增 4K prefill；命中缓存比 miss 便宜多个数量级。集群用 session cache affinity + 双集群一致性哈希容灾，并按请求类别分配预算，避免百万 token 突发饿死 2K 以下短请求。

成本效率：有代表性，不是统一会计口径

  • Kimi Code Bench 2.0：比 Claude Fable 5 低 4.0 分，成本为其 38%；K3 high effort 约用三分之一成本达到 Claude Opus 4.8 max 分数。

网络安全：能力与风险同时上升

Tier 1 漏洞发现

数十个广泛部署系统中产生数百候选；经人工复核者约 70% 为真实漏洞，包括 6 个项目中的 16 个此前未知漏洞。论文举出 Linux 内核远程堆越界写和 RDMA 权限检查缺失两例。

Tier 2 端到端利用

内部 36 题中 K3 解出 14 题（38.9%），GLM-5.2 为 8 题（22.2%）；K3 的 14 个成功中 10 个来自 user-space。全套均经人类验证可解，估计需 540 专家小时。

UK AISI 与 NIST CAISI 独立评估：ExploitBench 32% 对 GLM-5.2 的 24%；32 步模拟企业网络推进 17 步对 11 步；但 41 个端到端任务中任意代码执行为 0 / 41。报告指出困难集中在利用链最后一段、缓解措施下策略选择、无效调试循环和提交前验证。

风险说明论文称这是当前版本和覆盖范围下的能力下界。由于前沿模型常拒绝网络安全任务，部分对比不可做；“更低评测分”也不应被解释为没有滥用风险。

12报告案例：看“长程闭环”而非单次回答

内核优化

每题最多 24 小时。AttnRes 从 283.6ms 降到 114.4ms；DSA / KDA 运行时分别降 55.1% / 73.6%；MLA 达峰值 TFLOPS 一半以上。

MiniTriton 编译器

从 Python tile DSL、MLIR 标注优化到 PTX 与 runtime；L20 上 tensor-core matmul 大 shape 达实测 roofline 约 90%，并可端到端训练 GPT。

推理芯片

单次 48 小时自主运行，Nangate45；4mm²、100MHz、RTL 模拟超过 8,700 token/s，1.46M 标准单元与 0.277MiB SRAM。

13局限：报告结论与部署警戒线

对 thinking history 敏感

K3 以保留完整思考历史的模式训练。harness 若没有原样回传历史 thinking，或会话中途从另一模型切换到 K3，生成质量可能高度不稳定。报告建议使用已验证兼容的 Kimi Code，避免中途切换。

可能过度主动

长程困难任务训练使它遇到小问题或意图含糊时，可能替用户做意外决定。边界严格的应用应在 system prompt 或 AGENTS.md 明确许可、禁止项、确认点和终止条件。

体验与最高前沿仍有差距

报告明确承认综合用户体验落后 Claude Fable 5 和 GPT-5.6 Sol；HLE、CritPt、部分 computer-use、MIRA、24/7 Claw、Agent Behavior 与 agentic vision 也暴露差距。

评测可比性和披露边界

不同 harness、fallback、cyber guard、内部题集、模型评委与日期会影响结果。训练语料规模、总 FLOPs、硬件总量、训练能耗等并未在正文给出，不能从参数量自行补算为“论文事实”。

14术语表：读完能复述

MoE
Mixture of Experts。每个 token 只路由到少量专家，以总参数换取稀疏计算。
KDA
Kimi Delta Attention。用带遗忘门的固定大小递归状态进行序列混合。
MLA
Multi-head Latent Attention。压缩 K/V 缓存但保留全局 softmax 注意力。
NoPE
No Position Encoding。MLA 不显式加位置编码，KDA 门控隐式承载位置信息。
AttnRes
Attention Residuals。当前层对先前层或块表示做选择性加权读取。
LatentMoE
路由专家在低维 latent 中工作，共享专家保留完整宽度。
RMSNorm
按均方根归一化，稳定表示尺度；K3 用于 KDA、AttnRes、MoE 和 ViT 等位置。
SiTU-GLU
Sigmoid Tanh Unit GLU。用平滑 tanh cap 限制乘法分支的极端激活。
QB
Quantile Balancing。按 router margin 分位数更新专家 bias，使负载接近目标。
Muon
对矩阵参数的动量做 Newton-Schulz 正交化的优化器；K3 的 Q/K/V 逐 head 处理。
SFT / RL
监督微调提供冷启动；强化学习通过环境奖励强化推理与执行策略。
MOPD
Multi-Teacher On-Policy Distillation。将 9 个领域 / 努力度专家蒸馏进单一模型。
QAT
Quantization-Aware Training。训练时模拟量化误差，使低精度部署损失更可控。
MTP / EAGLE-3
多 token 预测层可改造成 draft model，用投机解码减少目标模型逐 token 开销。
Prefill / Decode
先处理已有上下文建立缓存，再逐 token 生成输出；两阶段瓶颈不同。
Context Parallelism
沿序列切分到多个计算单元；KCP 交换固定大小 KDA 状态片段。
EP / PP / DP
专家并行、流水线并行、数据并行，是 3T 级训练的不同切分轴。
Agent harness
包住模型的工具接口、系统提示、上下文管理、记忆与 subagent 运行框架。
